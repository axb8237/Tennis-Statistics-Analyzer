# Tennis-Statistics-Analyzer
Project Goal: Build a Python program that analyzes and compares tennis player statistics.


MVP Scope: Read tennis data from a CSV, Calculate performance metrics such as serve percentage and break point conversion rate, Compare players, Display the results in the terminal.


Future Plans: Create visual representations of player statistics; Filter stats by tournament, year and surface; Analyze player performances across multiple matches.


Tech Stack: 
      
Programming Language: Python

Libraries: Pandas and Matplotlib
            
Data Storage: CSV file
            
Data collection: Kaggle
